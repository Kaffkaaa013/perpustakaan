#### 4.2.3 Source Code Soal No. 3 (API Resource Controller & Model Buku)
**`BukuController.php`**
```php
<?php

namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use App\Http\Requests\StoreBukuRequest;
use App\Http\Requests\UpdateBukuRequest;
use App\Models\Buku;
use Illuminate\Http\Request;

class BukuController extends Controller
{
    public function index(Request $request)
    {
        $query = Buku::with('kategori')
            ->withCount(['peminjamans', 'peminjamans as peminjaman_count'])
            ->latest();

        // Pencarian berdasarkan judul atau penulis
        if ($request->filled('cari')) {
            $cari = $request->input('cari');
            $query->where(function ($q) use ($cari) {
                $q->where('judul', 'like', "%{$cari}%")
                    ->orWhere('penulis', 'like', "%{$cari}%");
            });
        }

        // Filter berdasarkan kategori (ID atau nama kategori)
        if ($request->filled('kategori')) {
            $kategori = $request->input('kategori');
            $query->where(function ($q) use ($kategori) {
                if (is_numeric($kategori)) {
                    $q->where('kategori_id', $kategori);
                } else {
                    $q->whereHas('kategori', function ($sub) use ($kategori) {
                        $sub->where('nama', 'like', "%{$kategori}%");
                    });
                }
            });
        } elseif ($request->filled('kategori_id')) {
            $query->where('kategori_id', $request->input('kategori_id'));
        }

        // Filter berdasarkan tahun terbit
        if ($request->filled('tahun')) {
            $query->where('tahun_terbit', $request->input('tahun'));
        } elseif ($request->filled('tahun_terbit')) {
            $query->where('tahun_terbit', $request->input('tahun_terbit'));
        }

        // Pagination 10 data per halaman dengan mempertahankan query string
        $bukus = $query->paginate(10)->withQueryString();

        return response()->json($bukus, 200);
    }

    public function store(StoreBukuRequest $request)
    {
        $buku = Buku::create($request->validated());

        $buku->load('kategori')->loadCount(['peminjamans', 'peminjamans as peminjaman_count']);

        return response()->json([
            'success' => true,
            'message' => 'Data buku berhasil ditambahkan.',
            'data'    => $buku,
        ], 201);
    }

    public function show(Buku $buku)
    {
        $buku->load('kategori')->loadCount(['peminjamans', 'peminjamans as peminjaman_count']);

        return response()->json([
            'success' => true,
            'message' => 'Detail data buku.',
            'data'    => $buku,
        ], 200);
    }

    public function update(UpdateBukuRequest $request, Buku $buku)
    {
        $buku->update($request->validated());

        $buku->load('kategori')->loadCount(['peminjamans', 'peminjamans as peminjaman_count']);

        return response()->json([
            'success' => true,
            'message' => 'Data buku berhasil diperbarui.',
            'data'    => $buku,
        ], 200);
    }

    public function destroy(Buku $buku)
    {
        $buku->delete();

        return response()->json([
            'success' => true,
            'message' => 'Data buku berhasil dihapus.',
        ], 200);
    }
}
```

**`Buku.php`**
```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;

class Buku extends Model
{
    use HasFactory;

    protected $table = 'bukus';

    protected $fillable = [
        'kategori_id',
        'judul',
        'penulis',
        'tahun_terbit',
    ];

    public function kategori()
    {
        return $this->belongsTo(Kategori::class, 'kategori_id');
    }

    public function peminjamans()
    {
        return $this->hasMany(Peminjaman::class, 'buku_id');
    }

    public function peminjaman()
    {
        return $this->hasMany(Peminjaman::class, 'buku_id');
    }

    public function getTahunAttribute()
    {
        return $this->tahun_terbit;
    }

    public function getKategoriAttribute()
    {
        $kategoriModel = $this->getRelationValue('kategori');
        if (! $kategoriModel) {
            $kategoriModel = $this->kategori()->first();
        }

        return $kategoriModel ? $kategoriModel->nama : '-';
    }
}
```

```php
<?php

namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use App\Models\Buku;
use App\Models\Kategori;

class RekapController extends Controller
{
    public function bukuPerKategori()
    {
        $rekap = Kategori::withCount([
            'bukus',
            'bukus as total_buku',
            'bukus as jumlah_buku',
        ])->get();

        return response()->json([
            'success' => true,
            'message' => 'Rekap jumlah buku per kategori berhasil diambil.',
            'data'    => $rekap,
        ], 200);
    }

    public function peminjamanPerBuku()
    {
        $rekap = Buku::with('kategori')
            ->withCount([
                'peminjamans',
                'peminjamans as peminjaman_count',
                'peminjamans as total_peminjaman',
                'peminjamans as jumlah_peminjaman',
            ])->get();

        return response()->json([
            'success' => true,
            'message' => 'Rekap peminjaman per buku berhasil diambil.',
            'data'    => $rekap,
        ], 200);
    }
}
```

```php
<?php

namespace Tests\Feature;

use App\Models\Buku;
use App\Models\Kategori;
use Illuminate\Foundation\Testing\RefreshDatabase;
use Tests\TestCase;

class ApiBukuTest extends TestCase
{
    use RefreshDatabase;

    protected function setUp(): void
    {
        parent::setUp();
        $this->artisan('db:seed');
    }

    public function test_api_buku_index_returns_paginated_list(): void
    {
        $response = $this->getJson('/api/buku');
        $response->assertStatus(200)
            ->assertJsonStructure(['current_page', 'data', 'per_page', 'total']);
        $this->assertEquals(10, $response->json('per_page'));
    }

    public function test_api_buku_store_validation_errors(): void
    {
        $response = $this->postJson('/api/buku', []);
        $response->assertStatus(422)
            ->assertJsonValidationErrors(['kategori_id', 'judul', 'penulis', 'tahun_terbit']);
        $this->assertEquals('Kategori wajib dipilih.', $response->json('errors.kategori_id.0'));
    }

    public function test_api_buku_store_success(): void
    {
        $kategori = Kategori::first();
        $response = $this->postJson('/api/buku', [
            'kategori_id'  => $kategori->id,
            'judul'        => 'Clean Code Indonesia',
            'penulis'      => 'Robert C. Martin',
            'tahun_terbit' => 2008,
        ]);
        $response->assertStatus(201)->assertJsonPath('success', true);
        $this->assertDatabaseHas('bukus', ['judul' => 'Clean Code Indonesia']);
    }

    public function test_rekap_endpoints(): void
    {
        $this->getJson('/api/rekap/buku-per-kategori')->assertStatus(200)->assertJsonPath('success', true);
        $this->getJson('/api/rekap/pemminjaman-per-buku')->assertStatus(200)->assertJsonPath('success', true);
    }
}
```

### 4.3 Penjelasan

#### 4.4.1 Penjelasan Soal No. 1
Pada soal ini dilakukan pendefinisian routing API pada file `routes/api.php`. Untuk entitas buku, digunakan `Route::apiResource('buku', BukuController::class)`. Berbeda dengan resource web biasa yang menyediakan method create dan edit untuk menampilkan form antarmuka Blade, `apiResource` hanya mendaftarkan 5 endpoint stateless yang murni menangani transfer data JSON, yaitu `index` (GET), `store` (POST), `show` (GET), `update` (PUT/PATCH), dan `destroy` (DELETE). Selain itu, dibuat grup prefix `/rekap` untuk menampung endpoint rekapitulasi data.

#### 4.4.2 Penjelasan Soal No. 2
Untuk menjaga validitas data sebelum disimpan atau diperbarui ke database, dibuat dua Form Request yaitu `StoreBukuRequest` dan `UpdateBukuRequest`. Aturan validasi diterapkan pada `kategori_id` (wajib dan harus ada di tabel kategoris), `judul` dan `penulis` (wajib berupa teks maksimal 255 karakter), serta `tahun_terbit` (wajib berupa angka 4 digit). Melalui method `messages()` dan `attributes()`, pesan galat dan nama atribut dikustomisasi ke dalam bahasa Indonesia agar ramah pengguna. Jika request gagal divalidasi, Laravel secara otomatis mengembalikan response JSON dengan status code **422 Unprocessable Content** tanpa mengeksekusi controller lebih lanjut.

#### 4.4.3 Penjelasan Soal No. 3
Implementasi CRUD dan manipulasi data diatur di dalam `BukuController`. Pada method `index`, diterapkan eager loading `with('kategori')` guna mencegah masalah query *N+1*, serta `withCount('peminjamans')` untuk menghitung total peminjaman buku tersebut. Method ini juga mendukung pencarian kata kunci (`cari`) pada judul atau penulis, filter kategori (`kategori`), dan filter tahun terbit (`tahun`). Seluruh data diurutkan dari yang terbaru (`latest()`) dan dibatasi menggunakan pagination 10 data per halaman dengan `withQueryString()` agar filter pencarian tetap terbawa saat berpindah halaman. Untuk method `store`, data disimpan menggunakan `$request->validated()` dengan status HTTP **201 Created**, sedangkan method `show`, `update`, dan `destroy` mengembalikan status **200 OK**.

#### 4.4.4 Penjelasan Soal No. 4
Pada soal ini dibuat `RekapController` untuk menangani kalkulasi agregasi data statistik perpustakaan. Method `bukuPerKategori()` memanfaatkan `Kategori::withCount('bukus')` untuk menghitung berapa banyak buku yang terdaftar di setiap kategori. Sedangkan method `peminjamanPerBuku()` memanfaatkan `Buku::withCount('peminjamans')` untuk mengetahui frekuensi peminjaman tiap judul buku. Response disajikan dalam format JSON terstandar yang dilengkapi properti `success`, `message`, dan `data`.

#### 4.4.5 Penjelasan Soal No. 5
Tahap terakhir adalah pengujian API untuk memastikan seluruh endpoint bekerja sesuai spesifikasi dan tidak mengalami regresi sistem. Pengujian dilakukan melalui dua pendekatan: pengujian otomatis (*automated feature testing*) menggunakan PHPUnit (`ApiBukuTest.php`) dan pengujian manual menggunakan Postman. Pada pengujian otomatis, dijalankan skenario pengujian terhadap struktur JSON, pagination 10 data, validasi respon pesan bahasa Indonesia, transaksi CRUD, hingga endpoint rekap. Seluruh 15 test berhasil lolos (100% passed). Koleksi Postman juga disediakan untuk memudahkan pengujian manual dengan berbagai variasi parameter query dan payload JSON.
